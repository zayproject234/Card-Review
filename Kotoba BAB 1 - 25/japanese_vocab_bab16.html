Romaji Hiragana Kanji / Katakana Arti & Catatan
🔷 Kata Kerja (動詞)
norimasu 1 のります 乗ります
naik (kendaraan)
乗る → kelompok 1; 電車に乗ります = naik kereta; partikel に untuk kendaraan yang dinaiki
arimasu 1 あります あります
ada / terdapat (acara/jadwal)
di bab 16 dipakai untuk menyatakan ada acara/jadwal; 会議があります = ada rapat; 授業があります = ada pelajaran
norikaemasu 2 のりかえます 乗り換えます
transit / berganti kendaraan
乗り (naik) + 換え (ganti); 新宿で乗り換えます = transit di Shinjuku
orimasu 2 おります 降ります
turun (dari kendaraan)
降りる → kelompok 2; 電車を降ります = turun dari kereta; lawan kata dari 乗ります (naik)
abimasu 2 あびます 浴びます
mandi (shower) / terkena
シャワーを浴びます = mandi shower; 日光を浴びます = terkena sinar matahari; kelompok 2
iremasu 2 いれます 入れます
memasukkan
入れる → kelompok 2; 箱に入れます = memasukkan ke kotak; berlawanan dengan 出します
dashimasu 1 だします 出します
mengeluarkan / mengumpulkan / mengirimkan
出す → kelompok 1; 手紙を出します = mengirim surat; 宿題を出します = mengumpulkan PR
oroshimasu 1 おろします 下ろします
menurunkan / menarik (uang)
下ろす → kelompok 1; お金を下ろします = menarik uang (di ATM); 荷物を下ろします = menurunkan barang
hairimasu 1 はいります 入ります
masuk / mandi (berendam)
入る → kelompok 1; お風呂に入ります = mandi berendam; 部屋に入ります = masuk ke kamar
demasu 2 でます 出ます
keluar / berangkat / terbit
出る → kelompok 2; 家を出ます = keluar dari rumah; 電車が出ます = kereta berangkat
oshimasu 1 おします 押します
menekan / mendorong
押す → kelompok 1; ボタンを押します = menekan tombol; ドアを押します = mendorong pintu
nomimasu 1 のみます 飲みます
minum / menelan (obat)
di bab 16 konteks baru: 薬を飲みます = minum obat; sudah dipelajari di bab 6 untuk minuman
hajimemasu 2 はじめます 始めます
memulai
始める → kelompok 2; 仕事を始めます = memulai pekerjaan; 授業を始めます = memulai pelajaran
kengaku shimasu 3 けんがくします 見学します
kunjungan belajar / observasi lapangan
見 (melihat) + 学 (belajar) + します; 工場を見学します = mengunjungi pabrik
denwa shimasu 3 でんわします 電話します
menelepon
電話 (telepon) + します; 友達に電話します = menelepon teman; sudah dikenal sejak bab awal
✨ Kata Sifat (形容詞)
wakai い わかい 若い
muda / masih muda
若い人 = orang muda; 若く見えます = terlihat muda; berlawanan dengan 年を取った (sudah tua)
nagai い ながい 長い
panjang / lama
長い髪 = rambut panjang; 長い時間 = waktu yang lama; berlawanan dengan 短い
mijikai い みじかい 短い
pendek (panjang) / sebentar
短い髪 = rambut pendek; 短い時間 = waktu sebentar; berlawanan dengan 長い
akarui い あかるい 明るい
cerah / terang / ceria
明るい部屋 = kamar yang terang; 明るい人 = orang yang ceria; berlawanan dengan 暗い
kurai い くらい 暗い
gelap / suram
暗い部屋 = kamar yang gelap; 暗い夜 = malam yang gelap; berlawanan dengan 明るい
👤 Anggota Tubuh (体の部位)
karada からだ 体
tubuh / badan
体が丈夫です = badannya kuat; 体に悪い = tidak baik untuk tubuh; 体の調子 = kondisi tubuh
atama あたま 頭
kepala / otak
頭が痛いです = sakit kepala; 頭がいい = otaknya bagus/pintar
kami かみ 髪
rambut (kepala)
長い髪 = rambut panjang; 黒い髪 = rambut hitam; berbeda dengan 紙 (kami) = kertas
kao かお 顔
wajah / muka
きれいな顔 = wajah cantik; 顔を洗います = mencuci muka
me め 目
mata
大きい目 = mata besar; 目が痛いです = mata sakit; 目を閉じます = menutup mata
mimi みみ 耳
telinga
耳が痛いです = telinga sakit; 耳がいい = pendengarannya bagus
hana はな 鼻
hidung
鼻が高い = hidung mancung; 鼻水が出ます = keluar ingus; berbeda dengan 花 (hana) = bunga
kuchi くち 口
mulut
口を開けてください = tolong buka mulutnya; 口が大きい = mulutnya besar
ha は 歯
gigi
歯が痛いです = sakit gigi; 歯を磨きます = menggosok gigi; 歯医者 = dokter gigi
onaka おなか お腹
perut
お腹が痛いです = sakit perut; お腹がすきました = lapar; お腹がいっぱいです = kenyang
ashi あし 足
kaki / tungkai
足が痛いです = kaki sakit; 足が長い = kakinya panjang; juga mencakup seluruh kaki dari pinggul ke bawah
se / せい せ・せい 背
tinggi badan / punggung
背が高いです = tinggi badannya tinggi; 背が低いです = tinggi badannya pendek; 背中 (senaka) = punggung
🏃 Kegiatan & Tempat (活動・場所)
saabisu サービス ―
layanan / servis / gratis
kata serapan dari "service"; サービスがいいです = pelayanannya bagus; サービス品 = barang gratis/bonus
jogingu ジョギング ―
joging / lari santai
kata serapan dari "jogging"; ジョギングをします = joging; 毎朝ジョギングをします = joging setiap pagi
shawaa シャワー ―
shower / mandi pancuran
kata serapan dari "shower"; シャワーを浴びます = mandi shower; berbeda dengan お風呂に入ります (mandi berendam)
midori みどり 緑
hijau / alam hijau / taman
緑が多い = banyak hijau/taman; 緑色 = warna hijau; 緑の多い公園 = taman yang banyak pepohonan
otera おてら お寺
kuil Buddha / vihara
お + 寺 (kuil); tempat ibadah Buddha di Jepang; 京都のお寺 = kuil di Kyoto
jinja じんじゃ 神社
kuil Shinto / shrine
神 (dewa/kami) + 社 (tempat); tempat ibadah Shinto; 神社に参ります = mengunjungi kuil Shinto
🔢 Kata Penghitung Nomor/Urutan (番)
〜ban 〜ばん 〜番
penghitung untuk nomor urut / giliran
何番ですか = nomor berapa?; 一番線 = jalur/peron nomor 1; 3番のバス = bus nomor 3; juga dipakai untuk "paling" pada 一番 (ichiban) = nomor satu/paling
❓ Kata Tanya & Ekspresi (疑問詞・表現)
douyatte どうやって ―
bagaimana caranya / dengan cara apa
どうやって行きますか = bagaimana caranya pergi ke sana?; menanyakan cara/metode melakukan sesuatu
dono どの ―
yang mana (sebelum kata benda)
どの電車 = kereta yang mana; どのバス = bus yang mana; selalu diikuti kata benda
dore どれ ―
yang mana (berdiri sendiri / 3+ pilihan)
どれですか = yang mana?; untuk 3 pilihan ke atas; どの + KB vs どれ (berdiri sendiri)
