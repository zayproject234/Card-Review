Romaji Hiragana Kanji / Katakana Arti & Catatan
🔷 Kata Kerja (動詞)
okimasu 1 おきます 置きます
meletakkan / menempatkan
置く → kelompok 1 (berakhiran く); 机の上に置きます = meletakkan di atas meja; berbeda dengan 起きます (bangun tidur)
tsukurimasu 1 つくります 作ります
membuat / memproduksi
作る → kelompok 1; 料理を作ります = membuat masakan; 製品を作ります = memproduksi produk
urimasu 1 うります 売ります
menjual
売る → kelompok 1; berlawanan dengan 買います; ここで売っています = dijual di sini
shirimasu 1 しります 知ります
mengetahui / mengenal
知る → kelompok 1; 知っています = sudah tahu (bentuk yang dipakai); 知りません = tidak tahu
sumimasu 1 すみます 住みます
tinggal / bertempat tinggal
住む → kelompok 1 (berakhiran む); 住んでいます = sedang tinggal; 東京に住んでいます = tinggal di Tokyo
kenkyuu shimasu 3 けんきゅうします 研究します
meneliti / melakukan penelitian
研究 + します → kelompok 3; 何を研究していますか = meneliti apa?; 研究者 = peneliti
📄 Dokumen & Materi (書類・資料)
shiryou しりょう 資料
materi / bahan referensi / dokumen
資 (modal/bahan) + 料 (bahan); 資料を送ります = mengirim materi; 会議の資料 = materi rapat
katarogu カタログ ―
katalog
kata serapan dari "catalogue"; カタログを送ってください = tolong kirimkan katalog
jikokuhyou じこくひょう 時刻表
jadwal kereta / tabel waktu
時刻 (waktu/jam) + 表 (tabel); 電車の時刻表 = jadwal kereta; sangat penting di Jepang
👔 Benda & Produk (物・製品)
fuku ふく 服
pakaian / baju
服を着ます = memakai pakaian; 服を買います = membeli pakaian; 洋服 (youfuku) = pakaian Barat
seihin せいひん 製品
produk / barang hasil produksi
製 (membuat/produksi) + 品 (barang); 新しい製品 = produk baru; 製品を作ります = memproduksi barang
sofuto ソフト ―
perangkat lunak / software
kependekan dari ソフトウェア (software); パソコンのソフト = software komputer
denshijisho でんしじしょ 電子辞書
kamus elektronik
電子 (elektronik) + 辞書 (kamus); 電子辞書を使います = menggunakan kamus elektronik
🏛️ Bidang & Institusi (分野・機関)
keizai けいざい 経済
ekonomi
経 (mengelola) + 済 (menyelesaikan); 経済学 = ilmu ekonomi; 経済の勉強をします = belajar ekonomi
shiyakusho しやくしょ 市役所
kantor pemerintahan kota / balai kota
市 (kota) + 役所 (kantor pemerintahan); 市役所に行きます = pergi ke balai kota; untuk urusan administrasi
koukou こうこう 高校
SMA / sekolah menengah atas
kependekan dari 高等学校; 高校生 = siswa SMA; 高校の友達 = teman SMA
haisha はいしゃ 歯医者
dokter gigi / klinik gigi
歯 (gigi) + 医者 (dokter); 歯医者に行きます = pergi ke dokter gigi; 歯が痛い = sakit gigi
💬 Status & Ekspresi (状態・表現)
dokushin な どくしん 独身
lajang / belum menikah
独 (sendiri) + 身 (diri); 独身です = masih lajang; berlawanan dengan 結婚しています
sumimasen ga すみませんが ―
permisi / maaf tapi... / boleh saya bertanya...
すみません + が (tapi); dipakai untuk membuka pertanyaan atau permintaan sopan kepada orang yang belum dikenal
