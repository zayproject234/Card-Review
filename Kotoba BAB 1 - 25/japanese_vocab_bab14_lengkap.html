📘 BAB 14
Romaji Hiragana Kanji / Katakana Arti & Catatan
🔷 Kata Kerja — Pasangan Berlawanan (対義語動詞)
tsukemasu 2 つけます つけます
menyalakan (lampu/AC)
電気をつけます = menyalakan lampu; エアコンをつけます = menyalakan AC; berlawanan dengan 消します
keshimasu 1 けします 消します
mematikan (lampu/AC) / menghapus
電気を消します = mematikan lampu; berlawanan dengan つけます; juga 消しゴム (penghapus)
akemasu 2 あけます 開けます
membuka (pintu/jendela)
ドアを開けます = membuka pintu; 窓を開けます = membuka jendela; berlawanan dengan 閉めます
shimemasu 2 しめます 閉めます
menutup (pintu/jendela)
ドアを閉めます = menutup pintu; berlawanan dengan 開けます
isogirnasu 1 いそぎます 急ぎます
terburu-buru / bergegas
急いでください = tolong bergegas; 急いで行きます = pergi dengan terburu-buru
machimasu 1 まちます 待ちます
menunggu
ちょっと待ってください = tolong tunggu sebentar; 駅で待ちます = menunggu di stasiun
torimasu 1 とります 取ります
mengambil / meraih
写真を取ります = mengambil foto; 塩を取ってください = tolong ambilkan garam
tetsudaimasu 1 てつだいます 手伝います
membantu
手 (tangan) + 伝 (menyampaikan); 手伝ってください = tolong bantu; 仕事を手伝います = membantu pekerjaan
yobimasu 1 よびます 呼びます
memanggil
名前を呼びます = memanggil nama; タクシーを呼びます = memanggil taksi
hanashimasu 1 はなします 話します
berbicara / bercerita
日本語で話します = berbicara dalam bahasa Jepang; ゆっくり話してください = tolong bicara pelan-pelan
tsukaimasu 1 つかいます 使います
memakai / menggunakan
パソコンを使います = memakai laptop; はしを使います = memakai sumpit
tomemasu 2 とめます 止めます
menghentikan / memarkirkan
車を止めます = memarkirkan mobil; ここで止めてください = tolong berhenti di sini
mochimasu 1 もちます 持ちます
membawa / memegang / memiliki
荷物を持ちます = membawa barang; 持ってください = tolong bawakan/pegangkan; お金を持っています = memiliki uang
misemasu 2 みせます 見せます
memperlihatkan / menunjukkan
パスポートを見せてください = tolong tunjukkan paspor; 地図を見せます = memperlihatkan peta
oshiemasu 2 おしえます 教えます
mengajar / memberitahu
住所を教えてください = tolong beritahu alamatnya; 読み方を教えます = mengajarkan cara membaca
suwarimasu 1 すわります 座ります
duduk
座ってください = tolong duduk; ここに座ります = duduk di sini; berlawanan dengan 立ちます
tachimasu 1 たちます 立ちます
berdiri
立ってください = tolong berdiri; berlawanan dengan 座ります
hairimasu 1 はいります 入ります
masuk
部屋に入ります = masuk ke kamar; 入ってください = silakan masuk; berlawanan dengan 出ます
demasu 2 でます 出ます
keluar / berangkat
部屋を出ます = keluar dari kamar; 家を出ます = berangkat dari rumah; berlawanan dengan 入ります
furimasu 1 ふります 降ります
turun (hujan/salju)
雨が降ります = hujan turun; 雪が降ります = salju turun; sudah dipelajari di bab 12
kopiishimasu 3 コピーします ―
mengkopi / memfotokopi
kata serapan dari "copy" + します; 書類をコピーします = memfotokopi dokumen
🏠 Benda & Peralatan (物・機器)
denki でんき 電気
lampu / listrik
電気をつけます = menyalakan lampu; 電気を消します = mematikan lampu; 電気代 = tagihan listrik
eakon エアコン ―
AC / pendingin ruangan
kependekan dari エアーコンディショナー (air conditioner); エアコンをつけます = menyalakan AC
pasupooto パスポート ―
paspor
kata serapan dari "passport"; パスポートを見せてください = tolong tunjukkan paspor
📝 Informasi & Dokumen (情報・書類)
namae なまえ 名前
nama
名前を教えてください = tolong beritahu nama; お名前は？= nama Anda?
juusho じゅうしょ 住所
alamat
住 (tinggal) + 所 (tempat); 住所を教えてください = tolong beritahu alamat
chizu ちず 地図
peta
地 (tanah/bumi) + 図 (gambar/diagram); 地図を見せてください = tolong tunjukkan peta
🧂 Bumbu Dapur (調味料)
shio しお 塩
garam
塩を取ってください = tolong ambilkan garam; 塩辛い = terlalu asin
satou さとう 砂糖
gula
砂 (pasir) + 糖 (gula); 砂糖を入れます = memasukkan gula
📚 Pelajaran & Cara (学習・方法)
mondai もんだい 問題
soal / masalah / pertanyaan
問 (bertanya) + 題 (topik); 問題があります = ada masalah; 問題を解きます = mengerjakan soal
kotae こたえ 答え
jawaban
答え (jawaban) ← 答えます (menjawab); 答えを書いてください = tolong tulis jawabannya
yomikata よみかた 読み方
cara membaca
読み (membaca) + 方 (cara); この漢字の読み方を教えてください = tolong ajarkan cara baca kanji ini
〜kata 〜かた 〜方
cara 〜 / cara melakukan 〜
書き方 (cara menulis)、使い方 (cara menggunakan)、食べ方 (cara makan); 動詞 + 方 = cara melakukan
💬 Kata Keterangan & Ekspresi (副詞・表現)
massugu まっすぐ 真っ直ぐ
lurus / langsung
まっすぐ行ってください = tolong jalan lurus; 真っ直ぐ前 = tepat di depan
yukkuri ゆっくり ―
pelan-pelan / santai / perlahan
ゆっくり話してください = tolong bicara pelan-pelan; ゆっくり休んでください = tolong istirahat dengan santai
sugu すぐ 直ぐ
segera / langsung / sebentar lagi
すぐ来ます = segera datang; すぐそこ = tepat di sana (dekat sekali)
mata また 又
lagi / kembali / sampai jumpa
また来てください = tolong datang lagi; またね = sampai jumpa (santai)
ato de あとで 後で
nanti / setelah ini
後で電話します = nanti menelepon; 後で話しましょう = mari bicara nanti
mou sukoshi もうすこし もう少し
sedikit lagi / lebih sedikit
もう少しゆっくり話してください = tolong bicara sedikit lebih pelan; もう少し待ってください = tolong tunggu sedikit lagi
mou 〜 もう〜 もう〜
〜 lagi (dengan angka)
もう一度 = sekali lagi; もう一枚 = satu lembar lagi; もう少し = sedikit lagi
