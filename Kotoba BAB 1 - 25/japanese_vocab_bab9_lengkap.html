Romaji Hiragana Kanji / Katakana Arti & Catatan
🔷 Kata Kerja & Kata Sifat Penting (動詞・形容詞)
wakarimasu 動 わかります 分かります
mengerti / paham
kata kerja kelompok 1; 日本語が分かります = mengerti bahasa Jepang; diikuti partikel が
arimasu 動 あります あります
ada / memiliki (benda/hal)
kata kerja; お金があります = punya uang; 時間があります = punya waktu
suki な すき 好き
suka / menyukai
kata sifat な; 〜が好きです = suka 〜; 大好き (daisuki) = sangat suka; 好きじゃありません = tidak suka
kirei な きれい 綺麗
cantik / indah / bersih
kata sifat な (meski berakhiran い); きれいな花 = bunga indah; きれいな部屋 = kamar bersih
jouzu な じょうず 上手
pandai / mahir
kata sifat な; 〜が上手です = pandai dalam 〜; jangan dipakai untuk memuji kemampuan diri sendiri
heta な へた 下手
tidak pandai / kurang mahir
kata sifat な; 〜が下手です = tidak pandai 〜; berlawanan dengan 上手
🥤 Makanan & Minuman (食べ物・飲み物)
nomimono のみもの 飲み物
minuman
飲み (minum) + 物 (benda); 好きな飲み物 = minuman favorit
ryouri りょうり 料理
masakan / memasak
料理が好きです = suka memasak; 日本料理 = masakan Jepang
⚽ Olahraga & Hobi (スポーツ・趣味)
supootsu スポーツ ―
olahraga
kata serapan dari "sports"; スポーツが好きです = suka olahraga
yakyuu やきゅう 野球
baseball / bisbol
野 (lapangan) + 球 (bola); olahraga paling populer di Jepang
dansu ダンス ―
dansa / tari
kata serapan dari "dance"; ダンスが上手です = pandai menari
ryokou りょこう 旅行
perjalanan / wisata
旅 (perjalanan) + 行 (pergi); 旅行が好きです = suka berwisata
🎵 Musik & Seni (音楽・芸術)
ongaku おんがく 音楽
musik
音 (suara) + 楽 (menikmati); 音楽を聞きます = mendengarkan musik
uta うた 歌
lagu / nyanyian
歌を歌います = menyanyikan lagu; 歌が好きです = suka bernyanyi
kurashikku クラシック ―
musik klasik
kata serapan dari "classic"; クラシック音楽 = musik klasik
jazu ジャズ ―
jazz
kata serapan dari "jazz"; ジャズが好きです = suka jazz
konsaato コンサート ―
konser
kata serapan dari "concert"; コンサートに行きます = pergi ke konser
karaoke カラオケ ―
karaoke
dari 空 (kara = kosong) + オーケストラ (orkestra); lahir di Jepang
kabuki かぶき 歌舞伎
kabuki (seni pertunjukan tradisional Jepang)
歌 (lagu) + 舞 (tari) + 伎 (pertunjukan)
✍️ Tulisan & Bahasa (文字・言語)
e え 絵
gambar / lukisan
絵を描きます = menggambar; 絵が好きです = suka menggambar
ji じ 字
huruf / tulisan tangan
字が上手です = tulisan tangannya bagus; きれいな字 = tulisan rapi
kanji かんじ 漢字
kanji
漢 (Tiongkok/Han) + 字 (huruf); 漢字が難しいです = kanji itu sulit
hiragana ひらがな 平仮名
hiragana
aksara Jepang asli berbentuk melengkung; dipakai untuk kata Jepang asli dan partikel
katakana カタカナ 片仮名
katakana
aksara Jepang berbentuk lurus; dipakai untuk kata serapan asing
roomaji ローマじ ローマ字
romaji (huruf Latin untuk bahasa Jepang)
ローマ (Roma) + 字 (huruf)
💰 Uang & Waktu (お金・時間)
komakai okane こまかいおかね 細かいお金 い
uang receh / uang kecil
細かい = kata sifat い (kecil/detail) + お金 (uang); 細かいお金がありますか = ada uang receh?
chiketto チケット ―
tiket (konser/acara)
kata serapan dari "ticket"; berbeda dengan 切符 (kippu) = tiket kereta
jikan じかん 時間
waktu / durasi
時間があります = punya waktu; 時間がありません = tidak ada waktu
📋 Kegiatan & Urusan (用事・約束)
youji ようじ 用事
urusan / keperluan
用事があります = ada keperluan; sering dipakai sebagai alasan tidak bisa hadir
yakusoku やくそく 約束
janji / perjanjian
約束があります = ada janji; 約束をします = membuat janji
arubaito アルバイト ―
kerja paruh waktu
dari bahasa Jerman "Arbeit"; sering disingkat バイト; アルバイトをします = kerja paruh waktu
👨‍👩‍👧 Keluarga Lanjutan (家族)
goshujin ごしゅじん ご主人
suami (milik orang lain)
dipakai saat menyebut suami orang lain; ご主人はお元気ですか = apakah suami Anda sehat?
otto / shujin おっと・しゅじん 夫 / 主人
suami saya
dipakai saat menyebut suami sendiri kepada orang lain; 夫 lebih netral/modern
okusan おくさん 奥さん
istri (milik orang lain)
dipakai saat menyebut istri orang lain; lebih sopan dari 彼女
tsuma / kanai つま・かない 妻 / 家内
istri saya
dipakai saat menyebut istri sendiri; 妻 lebih netral; 家内 lebih tradisional
kodomo こども 子供
anak / anak-anak
子 (anak) + 供 (ikut); お子さん = anak (milik orang lain, sopan)
💬 Kata Keterangan & Ekspresi (副詞・表現)
yoku よく ―
sering / dengan baik
よく行きます = sering pergi; よく分かります = sangat mengerti
daitai だいたい 大体
kira-kira / hampir semua
大体わかります = kira-kira mengerti; 大体できました = hampir selesai
takusan たくさん 沢山
banyak
たくさん食べます = makan banyak; 友達がたくさんいます = punya banyak teman
sukoshi すこし 少し
sedikit / agak
少し分かります = mengerti sedikit; 少し難しい = agak sulit; berlawanan dengan たくさん
zenzen ぜんぜん 全然
sama sekali tidak
selalu dipakai dengan kalimat negatif; 全然分かりません = sama sekali tidak mengerti
hayaku はやく 早く / 速く
cepat / segera / lebih awal
早く = lebih awal (waktu); 速く = cepat (kecepatan); 早く来てください = tolong datang lebih awal
kara から ―
karena / oleh karena itu
〜から、〜 = karena...; 忙しいから、行きません = karena sibuk, tidak pergi
doushite どうして ―
kenapa / mengapa
どうして行きませんか = kenapa tidak pergi?; sering berpasangan dengan から sebagai jawaban
