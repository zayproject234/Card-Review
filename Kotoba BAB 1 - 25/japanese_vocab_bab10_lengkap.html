Romaji Hiragana Kanji / Katakana Arti & Catatan
🔷 Kata Kerja Keberadaan (存在動詞)
arimasu 動 あります あります
ada (benda mati / tumbuhan)
dipakai untuk benda tidak bergerak; 机があります = ada meja; berlawanan fungsi dengan います
imasu 動 います います
ada (orang / hewan)
dipakai untuk makhluk hidup yang bergerak; 猫がいます = ada kucing; 人がいます = ada orang
👥 Orang (人)
iroiro いろいろ 色々
berbagai macam / bermacam-macam
色々な人 = berbagai macam orang; いろいろあります = ada bermacam-macam
otoko no hito おとこのひと 男の人
laki-laki (orang dewasa)
男 (laki-laki) + の + 人 (orang); lebih sopan dari 男
onna no hito おんなのひと 女の人
perempuan (orang dewasa)
女 (perempuan) + の + 人 (orang); lebih sopan dari 女
otoko no ko おとこのこ 男の子
anak laki-laki
男 (laki-laki) + の + 子 (anak); untuk anak-anak
onna no ko おんなのこ 女の子
anak perempuan
女 (perempuan) + の + 子 (anak); untuk anak-anak
🐾 Hewan & Alam (動物・自然)
inu いぬ 犬
anjing
犬がいます = ada anjing; 犬が好きです = suka anjing
neko ねこ 猫
kucing
猫がいます = ada kucing; hewan peliharaan paling populer di Jepang
panda パンダ ―
panda
kata serapan; パンダがいます = ada panda; hewan populer di kebun binatang Jepang
zou ぞう 象
gajah
象がいます = ada gajah; kanji 象 berbentuk seperti gajah dari atas
ki き 木
pohon / kayu
木があります = ada pohon; 木の下 = di bawah pohon; 木曜日 juga mengandung kanji ini
📦 Benda & Perabot (物・家具)
mono もの 物
benda / barang
物があります = ada barang; 食べ物 (makanan)、飲み物 (minuman) juga mengandung 物
denchi でんち 電池
baterai
電 (listrik) + 池 (kolam/tempat); 電池があります = ada baterai
hako はこ 箱
kotak / kardus
箱の中に〜があります = di dalam kotak ada 〜
suicchi スイッチ ―
saklar / switch
kata serapan dari "switch"; ditulis katakana; ドアの近くにスイッチがあります
reizoko れいぞうこ 冷蔵庫
kulkas / lemari es
冷 (dingin) + 蔵 (menyimpan) + 庫 (gudang); 冷蔵庫の中に〜があります = di dalam kulkas ada 〜
teeburu テーブル ―
meja (makan)
kata serapan dari "table"; berbeda dengan 机 (tsukue) = meja belajar/kerja
beddo ベッド ―
tempat tidur / ranjang
kata serapan dari "bed"; ベッドの下に〜があります = di bawah tempat tidur ada 〜
tana たな 棚
rak / lemari terbuka
棚の上に〜があります = di atas rak ada 〜
doa ドア ―
pintu
kata serapan dari "door"; ドアの前に〜があります = di depan pintu ada 〜
mado まど 窓
jendela
窓の近くに〜があります = di dekat jendela ada 〜
🏙️ Tempat di Sekitar (町の場所)
posuto ポスト ―
kotak surat / pos
kata serapan dari "post (box)"; ポストがあります = ada kotak surat; berwarna merah di Jepang
beru ベル ―
bel / lonceng
kata serapan dari "bell"; ドアのベル = bel pintu
ATM エーティーエム ATM
ATM / mesin anjungan tunai mandiri
ATMがあります = ada ATM; 銀行のATM = ATM bank
konbini コンビニ ―
minimarket / convenience store
kependekan dari コンビニエンスストア; sangat umum di Jepang (7-Eleven, Lawson, FamilyMart)
kouen こうえん 公園
taman (umum)
公 (umum/publik) + 園 (taman); berbeda dengan 庭 (niwa) = taman pribadi di rumah
kissaten きっさてん 喫茶店
kafe / kedai kopi
喫 (menyeruput) + 茶 (teh) + 店 (toko); kafe tradisional Jepang; berbeda dari カフェ (kafe modern)
〜ya 〜や 〜屋
toko 〜 (sufiks toko)
パン屋 (toko roti)、本屋 (toko buku)、魚屋 (toko ikan)、花屋 (toko bunga)
noriba のりば 乗り場
halte / tempat naik kendaraan
乗り (naik) + 場 (tempat); バスの乗り場 = halte bus; タクシー乗り場 = pangkalan taksi
ken けん 県
prefektur / provinsi (di Jepang)
Jepang punya 47 県; 大阪県 = Prefektur Osaka; setara dengan provinsi di Indonesia
📍 Kata Posisi / Arah (位置を表す言葉)
ue 位置 うえ 上
atas / di atas
机の上に本があります = di atas meja ada buku
shita 位置 した 下
bawah / di bawah
ベッドの下に〜があります = di bawah tempat tidur ada 〜
mae 位置 まえ 前
depan / sebelum
駅の前にコンビニがあります = di depan stasiun ada minimarket
ushiro 位置 うしろ 後ろ
belakang
建物の後ろに公園があります = di belakang gedung ada taman
migi 位置 みぎ 右
kanan
受付の右に階段があります = di kanan resepsionis ada tangga
hidari 位置 ひだり 左
kiri
ドアの左にスイッチがあります = di kiri pintu ada saklar
naka 位置 なか 中
dalam / di dalam
箱の中に〜があります = di dalam kotak ada 〜; 冷蔵庫の中 = di dalam kulkas
soto 位置 そと 外
luar / di luar
建物の外に〜があります = di luar gedung ada 〜; berlawanan dengan 中
tonari 位置 となり 隣
sebelah / bersebelahan
銀行の隣に郵便局があります = di sebelah bank ada kantor pos; untuk benda/tempat yang bersebelahan langsung
chikaku 位置 ちかく 近く
dekat / di dekat
駅の近くにコンビニがあります = di dekat stasiun ada minimarket; lebih jauh dari 隣
aida 位置 あいだ 間
antara / di antara
銀行と郵便局の間にATMがあります = di antara bank dan kantor pos ada ATM
💬 Ekspresi (表現)
〜ya nado 〜やなど 〜や〜など
〜 dan 〜 dan lain-lain / seperti 〜
コンビニや銀行などがあります = ada minimarket, bank, dan lain-lain; dipakai untuk menyebut contoh tidak lengkap
